# 第五章 DRC 检查、Gerber 生产文件与表面工艺

> DRC 通过 ≠ 板子能用，但 DRC 不通过 = 板子多半用不了。它是出厂前的最后一道自动防线。本章把 DRC、Gerber、工厂工艺能力与表面处理一次性讲透，并补充叠层、阻抗控制与拼板这些量产必知项。

## 4.1 DRC 是什么

**DRC = Design Rule Check，设计规则检查。** 它校验的是**工艺可行性**，不校验电路原理是否正确。

| 检查项 | 典型规则 | 触发后果 |
| --- | --- | --- |
| 最小线宽 | 0.15 mm（普通工艺） | 蚀刻断线 |
| 最小线间距 | 0.15 mm | 短路 |
| 最小孔径 | 0.3 mm | 无法钻孔 |
| 丝印压焊盘 | 禁止 | 焊接不良 |
| 焊盘间距过近 | < 0.15 mm | 连锡 |
| 板框越界 | 器件/走线超框 | 铣边切伤 |
| 短路 / 开路 | 网表比对 | 功能失效 |
| 孤立焊盘（无网络） | 警告 | 潜在虚焊 |

> 关键认知：**DRC 全部通过，不代表电路功能一定正常**。原理图接错、封装选错、参数算错，DRC 一项都查不出来。

## 4.2 DRC 之外必须人工确认的事

1. **原理图与 PCB 网表一致性**（PCB 里执行「更新网表对比」）
2. **封装与实物是否匹配**（1:1 打印比对）
3. **电源与地的网络是否全部连通**（高亮 GND 网络看是否成片）
4. **元器件 BOM 与实物是否一致**（型号、封装、精度）
5. **安装孔、板框与结构件是否吻合**
6. **阻抗要求是否满足**（若做了受控阻抗）

## 4.3 叠层与阻抗控制

4 层板常见叠层：`L1 信号 / L2 地 / L3 电源 / L4 信号`。完整地平面给所有表层信号提供低阻抗回流，是高速稳定的基础。

需要做受控阻抗时（USB 90 Ω、以太网 100 Ω、RF 50 Ω），要**在下单时提供阻抗要求文件**，工厂据此调整介质厚度/线宽或做阻抗条（coupon）实测。普通低速板无需。

## 4.4 Gerber 文件说明

Gerber（RS-274X）是 PCB 工厂生产用的**光绘标准文件**，描述每一层的图形。常见层名：

| 层名 | 含义 | 备注 |
| --- | --- | --- |
| GTL | 顶层走线（Top Layer） | 单面板只有这一层铜 |
| GBL | 底层走线（Bottom Layer） | |
| GTS | 顶层阻焊（Top Solder Mask） | 开窗层 |
| GBS | 底层阻焊 | |
| GTO | 顶层丝印（Top Overlay） | 字符、极性标识 |
| GBO | 底层丝印 | |
| GKO / GML | 板框（Keepout / Mechanical） | 工厂按此铣边 |
| .TXT / Excellon | 钻孔文件（NC Drill） | 孔位与孔径 |
| GP1/GP2 | 内层走线（4 层及以上） | 电源/地平面 |

## 4.5 表面处理怎么选

裸铜会氧化，需要表面处理保护可焊性：

| 工艺 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- |
| HASL（喷锡） | 便宜、可焊性好 | 平整度差、含铅风险 | 普通板 |
| ENIG（沉金） | 平整、抗氧化、适合细间距/BGA | 成本高、有黑盘风险 | 精密/金手指 |
| OSP | 便宜、平整 | 存放期短、易氧化 | 大批量低成本 |
| 沉银/沉锡 | 平整 | 易硫化变色 | 特定需求 |

金手指（插槽金手指）通常用**硬金（镀金）**加厚耐磨。

## 4.6 打样交付清单

交给工厂的资料一般包含三类：

1. **Gerber 光绘包**（上述各层，通常打包成 zip）
2. **钻孔文件**（Excellon 格式，含孔位表）
3. **BOM 物料清单**（贴片/插件型号、封装、数量）

> 需要 SMT 贴片时还要提供**坐标文件（Pick & Place / Centroid）**，包含每个器件的位号、X/Y 坐标、旋转角度、所在层。同时附一份**工艺要求说明**（板厚、铜厚、阻焊颜色、表面处理、阻抗要求）。

## 4.7 拼板与成型

小板或大批量化生产要**拼板**：V-cut（V 形槽，直线分板）或邮票孔（异形/曲线分板）。板边留工艺边放基准点。注意 V-cut 处器件要离切割线 ≥ 1 mm，避免分板时崩边伤件。

## 4.8 常见 DRC 误报与处理

- **丝印在阻焊开窗外**：调整丝印位置即可，多为警告
- **焊盘到板框间距小**：确认是否故意（如板边连接器），否则移开
- **非连接焊盘告警**：若确为测试点可忽略，否则应连网络
- **差分等长未达标**：回到布线补蛇形

不要一律「忽略全部警告」，每条都要人眼确认。

## 4.9 输出前终检

- [ ] DRC 零错误（警告需逐条确认）
- [ ] 重新生成 Gerber，确认层数完整、无遗漏
- [ ] 用 Gerber 查看器（如 GC-Prevue / 在线预览）逐层目视检查
- [ ] 叠层与阻抗要求已附工艺说明
- [ ] 板框闭合、尺寸与下单参数一致
- [ ] 阻焊开窗正常，丝印不压焊盘
- [ ] 钻孔文件与孔径表匹配
- [ ] BOM 与坐标文件位号对齐
- [ ] 拼板方式与分板工艺匹配

**强烈建议**：每次打样前用 Gerber 查看器「像工厂一样」看一遍板子，这一步能拦下绝大多数低级失误。

## 本章要点

- DRC 只查工艺规则，不查电路逻辑
- 最小线宽/间距、丝印压焊盘是最常见报错
- 4 层叠层：信号-地-电源-信号；阻抗需附要求文件
- 表面处理：HASL 便宜、ENIG 平整、OSP 低成本
- Gerber 层级：GTL/GBL 铜、GTS/GBS 阻焊、GTO/GBO 丝印、GKO 板框
- 打样三件套：Gerber + 钻孔 + BOM；贴片再加坐标文件
- 输出前务必用 Gerber 查看器人工过一遍
