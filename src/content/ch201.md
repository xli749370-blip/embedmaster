# 第二章 封装库与焊盘基础

> 一个封装画错，整批板子作废。封装库是 PCB 设计里唯一「不允许凭记忆」的环节。本章先建立全局观，再深入封装库这一最易翻车的地方。

## 1.1 六步设计流程

1. **需求与选型**：确定板子尺寸、层数、关键器件、工作条件
2. **原理图**：画符号、连网络、标注 BOM 信息
3. **封装库**：建/校对 Symbol 与 Footprint（本章重点）
4. **PCB 布局**：摆放器件、定分区
5. **PCB 布线**：走线、铺铜、过孔
6. **检查与输出**：DRC、Gerber、打样

| KiCad | 开源免费、社区活跃 | 个人/教育/中小项目（本项目即用） |

## 1.3 层数与板材判据

| 层数 | 适用 | 成本 |
| --- | --- | --- |
| 1~2 层 | 低速、简单逻辑 | 最低 |
| 4 层 | 有高速信号/完整地平面 | 中等 |
| 6+ 层 | 高速、高密度、阻抗控制 | 较高 |

板材常用 FR-4（介电常数 $\varepsilon_r \approx 4.2$）。厚度常见 1.6 mm（板厚）、1 oz 铜厚（约 35 µm）。是否需要阻抗控制，决定要不要做叠层设计。

## 1.4 布线前必定的设计规则

在动手布线前，先设好约束，避免后期返工：

| 规则 | 常用值 | 说明 |
| --- | --- | --- |
| 最小线宽 | 0.2 mm（普通） | 电流大要加宽 |
| 最小间距 | 0.2 mm | 防短路 |
| 最小孔径 | 0.3 mm | 工厂可钻下限 |
| 丝印线宽 | ≥ 0.15 mm | 太细印不清 |
| 安全间距（安规） | ≥ 0.5 mm（低压） | 强电要更大 |

## 1.5 Symbol 与 Footprint 的区别

| | 原理图 Symbol | PCB Footprint |
| --- | --- | --- |
| 所在图纸 | 原理图（Schematic） | PCB 版图 |
| 定义内容 | 引脚名称、引脚编号、逻辑关系 | 焊盘位置、焊盘尺寸、丝印外形 |
| 是否有物理尺寸 | **没有** | **有**，必须 1:1 |
| 出错后果 | 网表错误、连线错位 | 器件装不上、无法回流焊 |

两者通过 **引脚编号（Pin Number）** 严格对应。Symbol 的引脚编号必须与 Footprint 的焊盘编号一一匹配，这是封装库检查的第一道关。

## 1.6 常见封装速查

| 封装 | 典型器件 | 引脚间距 | 焊接难度 |
| --- | --- | --- | --- |
| 0402 / 0603 / 0805 | 电阻、电容 | — | 0805 适合手工 |
| SOT-23 | 贴片三极管、MOS 管、LDO | 0.95 mm | 容易 |
| SOP-8 / SOIC-8 | 运放、EEPROM、驱动芯片 | 1.27 mm | 容易 |
| TSSOP-20 | MCU、逻辑芯片 | 0.65 mm | 中等 |
| QFN-32 | STM32、电源芯片 | 0.5 mm | 困难，需热风 |
| LQFP-48/64 | STM32F103/F407 | 0.5 mm | 中等，可拖焊 |
| TO-220 / TO-252 | 功率管、稳压器 | 2.54 mm | 容易，注意散热焊盘 |

## 1.7 焊盘尺寸必须查 Datasheet

**不要抄别人的封装，也不要凭感觉画。** 每个器件的 Datasheet 末尾都有一节
`Package Outline` / `Recommended Land Pattern`（推荐焊盘图形），包含：

- 焊盘长度 $L$ 与宽度 $W$
- 焊盘中心间距 $e$
- 阻焊开窗（Solder Mask）扩展量
- 钢网开孔（Solder Paste）面积比

IPC-7351 给出三个密度等级：

- **A 级（Most）**：最宽松，手工焊接、维修友好
- **B 级（Nominal）**：通用推荐
- **C 级（Least）**：最紧凑，高密度板，必须回流焊

> 原型打样建议统一用 **A 级或 B 级**，能显著降低手焊与返修难度。密度上去了良率会掉。

## 1.8 建封装的实操步骤（以 SOIC-8 为例）

1. 打开 Datasheet → 定位 `Recommended Land Pattern`
2. 量出焊盘尺寸（如 $L=1.55\,\text{mm}$、$W=0.6\,\text{mm}$）、间距 $e=1.27\,\text{mm}$
3. 在库编辑器里按 A 级放大焊盘，放置 8 个焊盘并编号 1~8
4. 画丝印外框（比本体大 0.2 mm），标 1 脚圆点
5. 加阻焊开窗（比焊盘大 0.1 mm）、钢网开孔（约焊盘 90% 面积）
6. 设 courtyard（占位边界）用于 DRC 间距检查
7. 1:1 打印比对实物

## 1.9 必须核对的五个要点

1. **引脚顺序方向**：以 Datasheet 的 Top View / Bottom View 标注为准，别搞混
2. **1 脚标识**：丝印圆点或缺角必须与器件 1 脚同侧
3. **极性器件**：二极管、电解电容、LED 要有清晰的极性丝印
4. **散热焊盘**：QFN / DFN 的中心裸露焊盘必须做，且打过孔到地平面
5. **装配干涉**：器件本体长宽要与丝印框一致，避免与邻件碰撞

## 1.10 常见封装错误清单

| 错误 | 后果 |
| --- | --- |
| 丝印压焊盘 | 焊接不良、丝印脱落 |
| 缺 courtyard | 器件间距检查失效，装不下 |
| 钢网漏画 | 贴片无锡，虚焊 |
| 焊盘尺寸错 | 偏移、立碑（tombstone） |
| 引脚编号错位 | 整片网络错乱 |

## 本章要点

- 六步流程：需求→原理图→封装→布局→布线→输出
- 工具选一个统一用；层数/板材按需求定，FR-4 最常用
- Symbol 管逻辑、Footprint 管物理，引脚编号是桥梁
- 焊盘尺寸只信 Datasheet 的推荐值，按 IPC-7351 A/B 级
- 建封装七步法；1 脚方向、极性丝印、散热焊盘是三大易错点
