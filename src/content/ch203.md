# 第四章 PCB 布线基础、电源与信号走线

> 布线不是「把线连上」，而是给每一股电流安排一条阻抗可控、回流完整的路径。本章从线宽、转角讲到过孔、差分、回流，再补上长度匹配、受控阻抗与电源分配网络这些进阶却高频的知识。

## 3.1 线宽由电流决定

经验值（1 oz 铜厚，温升 10 °C）：

| 电流 | 推荐线宽 | 典型用途 |
| --- | --- | --- |
| < 0.3 A | 0.25~0.3 mm | 普通低速信号 |
| 0.5 A | 0.5 mm | LED、小功率负载 |
| 1 A | 1.0 mm | 电源支路 |
| 2 A | 2.0 mm | 主电源输入 |
| 3 A 以上 | 铺铜 / 多层并联 | 电机、加热 |

**大电流走线一定加宽**，同时尽量缩短路径。双层板还可以在底层用大面积铺铜并联走线。

## 3.2 转角与走线形态

- 优先 **45° 折线**或**圆弧**
- **避免 90° 直角**：直角处线宽突变会引起阻抗不连续，蚀刻时也容易残留「酸角」
- 避免长距离平行走线（串扰）
- 一根线不要反复绕来绕去，先规划主干道

## 3.3 过孔为什么越少越好

每个过孔都会引入寄生参数：

$$L_{via} \approx 5.08\,h\left(\ln\frac{4h}{d}+1\right) \ \text{[nH]}, \qquad C_{via} \approx \frac{1.41\,\varepsilon_r T D_1}{D_2 - D_1} \ \text{[pF]}$$

- **寄生电感**：高速信号边沿变缓，产生地弹
- **寄生电容**：阻抗不连续，引起反射
- **工艺成本**：孔越多，钻孔与沉铜成本越高
- **可靠性**：孔是机械薄弱点，热循环易开裂

结论：**能用一层走完就不要换层**；必须换层时，旁边配一个回流地过孔。过孔还有类型之分：通孔（through）、盲孔（blind）、埋孔（buried）、热过孔（thermal via），后三种用于高密度 HDI 板。

## 3.4 差分信号四条铁律

| 要求 | 说明 |
| --- | --- |
| 走线等长 | 长度差控制在 5 mil 以内（USB2.0） |
| 紧密耦合 | 两条线间距恒定，全程等距 |
| 控制差分阻抗 | USB 90 Ω、以太网 100 Ω |
| 禁止随意转弯 | 转弯处两条线保持同步对称，不可分开绕行 |

差分线**不做等长补偿就等于没做差分**。补偿时在失配处加「蛇形」微调，且要成对补偿。

## 3.5 回流路径：最容易被忽略的一点

电流永远走**闭合回路**。信号从顶层流向负载，回流必须从地平面流回源端，且**紧贴信号线正下方**。

若地平面被分割、被过孔密集割裂，回流被迫绕远路，形成巨大环路面积 → 辐射与串扰急剧上升。

> 记住一句话：**信号线在哪一层，它的参考平面就在相邻层**。跨分割是高速设计的头号杀手。

## 3.6 受控阻抗与叠层

高速信号（USB、以太网、DDR）需要阻抗受控。以微带线（表层走线、下方为参考地）为例，特性阻抗近似：

$$Z_0 \approx \frac{87}{\sqrt{\varepsilon_r + 1.41}} \ln\left(\frac{5.98\,h}{0.8w + t}\right)$$

其中 $h$ 为介质厚度、$w$ 为线宽、$t$ 为铜厚。实际用阻抗计算工具或工厂提供的叠层参数反推线宽。4 层板常见叠层：`信号-地-电源-信号`，完整地平面为信号提供低阻抗回流。

## 3.7 长度匹配与蛇形线

并行总线（如 DDR 的数据/地址线）要求组内等长，偏差通常 < 50 mil。用**蛇形（serpentine）**走线补齐长度差，注意蛇形间距足够大以免自串扰。时钟线通常最长，其余以它为基准对齐。

## 3.8 串扰：容性与感性耦合

相邻走线间通过电场（容性）和磁场（感性）互相耦合，受害线出现噪声。抑制手段：

- **3W 原则**：间距 ≥ 3 倍线宽
- 敏感线与干扰源**正交**或拉开
- 中间插地线屏蔽（guard trace）
- 缩短平行段长度

## 3.9 电源分配网络（PDN）

电源不是「一根粗线」就完事。PDN 的目标是让每个芯片电源引脚看到足够低的**目标阻抗**：

$$Z_{target} = \frac{V_{ripple}}{I_{transient}}$$

做法：电源层低阻抗平面 + 大量去耦电容（大+小并联，覆盖不同频段）+ 就近放置。去耦电容的 ESL 决定其高频是否有效。

## 3.10 铺铜与接地

- 双层板底层大面积铺 GND，显著提升抗干扰能力
- 顶层可铺地并多打过孔缝合（Stitching Via），间距 < λ/20
- 铺铜与信号线之间保持 ≥ 0.3 mm 间距（避免短路风险）
- 死铜（孤立无连接的铜箔）应删除，否则会成为天线

## 3.11 关键信号优先级

布线顺序建议：电源 → 时钟/复位/参考源（最敏感）→ 差分高速 → 普通数字 → 模拟（独立处理）。时钟线尽量短、包地、少过孔。

## 3.12 布线自检清单

- [ ] 电源线宽满足电流，且路径最短
- [ ] 无 90° 直角走线
- [ ] 差分对等长、等距、阻抗受控
- [ ] 关键信号有完整参考平面，无跨分割
- [ ] 过孔数量合理，换层处有回流地孔
- [ ] 长度匹配已做（并行总线）
- [ ] 串扰已用 3W/屏蔽抑制
- [ ] PDN 去耦充分
- [ ] 铺铜已缝合，无孤立死铜

## 本章要点

- 线宽看电流，1 A 约需 1 mm
- 45° 或圆弧转角，拒绝直角；过孔三宗罪：寄生参数、成本、可靠性
- 差分四要素：等长、耦合、阻抗、对称；回流路径比走线本身更重要
- 受控阻抗靠叠层设计；长度匹配用蛇形，串扰靠 3W 原则
- PDN 目标低阻抗，靠电源平面 + 去耦电容阵列
