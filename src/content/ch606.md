# 第六章 整机调试、功耗优化与量产准备

> 功能能跑不代表能出货。这一章把"能演示"提升到"能稳定用三个月、能批量生产"。

## 6.1 整机调试清单

沿用"先电源后信号、先最小后外设"原则，逐项打勾：

- [ ] 3.3 V 轨电压与纹波达标（示波器看，非仅万用表）
- [ ] 各 VDD 去耦电容到位，NRST 为高
- [ ] SWD 可连、能读芯片 ID
- [ ] SHT30 能读出合理温湿度
- [ ] 串口能看到 MCU 发的数据
- [ ] 手机蓝牙能连、能收到帧
- [ ] 协议 CRC 全部通过
- [ ] 进 STOP 后平均电流达标

## 6.2 功耗实测方法

**不要用万用表电流档测平均电流**——它的采样率低，会把睡眠的尖峰平均掉，读数严重偏小。正确做法：

1. **电流分析仪 / 示波器 + 采样电阻**：在被测回路串一颗 1 Ω 电阻，用示波器量压降 $U$，$I = U / 1\,\Omega$，能看到每个唤醒尖峰。
2. **平均电流公式**：把一段典型周期（如 10 min）的电流曲线积分，再除以周期：

$$I_{avg} = \frac{1}{T} \int_0^T i(t)\,dt$$

3. **续航估算**：$t_{life} = \dfrac{Q_{battery}}{I_{avg}}$（如 2000 mAh / 14.6 μA ≈ 15 年理论值，现实按 3~6 月规划）。

## 6.3 功耗优化手段

从大到小砍电流：

| 手段 | 效果 | 注意事项 |
| --- | --- | --- |
| 进 STOP 而非仅空闲 | 省 1~2 个数量级 | 唤醒后重配时钟 |
| 降主频（如 8 MHz） | 动态功耗正比于 $f\cdot V^2$ | 满足实时性即可 |
| 关未用外设时钟 | 逐个 `RCC->APBxENR` 关 | 用前再开 |
| 延长睡眠周期 | 占空比 $D$ 变小 | 上报实时性下降，取平衡 |
| 蓝牙间歇广播 | 非连续广播 | 手机连接延迟略增 |

> 关键公式：动态功耗 $P \propto C \cdot f \cdot V^2$。降频与降压（在 LDO 允许范围）是性价比最高的两招。

## 6.4 故障树

遇到问题先画故障树，别盲改：

```
整机不工作
├─ 3.3V 无输出 → 查 LDO 输入/使能/焊点
├─ MCU 不启动 → NRST 电平、BOOT0、晶振起振
├─ 采不到温湿度 → I2C 地址左移、上拉、ADDR 引脚
├─ 蓝牙连不上 → 模块是否透传模式、波特率、天线净空
└─ 数据错 → 字节序、定点缩放、CRC
```

## 6.5 生产测试工装

量产前要给工厂/自己一套**自动化验收**手段：

1. **测试点（TP）**：在 3.3 V、GND、SWD、UART_TX 预留测试焊盘，方便针床接触。
2. **自动化烧录**：用 ST-Link + 脚本批量烧录固件并写入唯一序列号。
3. **自检固件**：上电先跑一段自测（读 ID、测传感器、回环 UART），通过则点绿灯。
4. **配置项**：上报周期、蓝牙名、校准系数存入 Flash，出厂前写一次。

## 6.6 出货与版本管理

- **固件版本**：帧里带版本号（如 `0x10` 表示 v1.0），便于售后区分。
- **序列号**：每片唯一，存 Flash，出问题可追溯批次。
- **质检记录**：抽样测续航、距离、温湿度偏差，留档。
- **OTA 预留**：协议里留 `0x05` 升级命令位（即使本期不实现，先把通道占住）。
