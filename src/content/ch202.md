# 第三章 PCB 布局基础原则

> 布局决定了布线 70% 的难度。布局阶段画错的那条线，布线阶段要花三倍时间绕回来。本章把「先放哪、怎么分区、哪些红线不能碰」讲透，并补充热设计、可测试性与可制造性这些原型阶段常被忽略的维度。

## 2.1 布局的优先级顺序

以 STM32 最小系统为例，**严格按这个顺序摆放**：

1. **主控 MCU**（先定中心，留出丝印与调试空间）
2. **晶振 + 负载电容**（紧贴 MCU 的 OSC 引脚，越近越好）
3. **复位电路**（NRST 上拉 + 电容 + 按键）
4. **去耦电容**（每个 VDD 引脚旁一颗 0.1 µF）
5. **电源芯片与滤波电容**（稳压输入输出电容就近）
6. **外接连接器、LED、按键等外设**

先核心、后就近、最后外设。这个顺序的本质是：**信号速率越高、越敏感，越优先靠近主控**。

## 2.2 接口必须靠边

USB、DC 电源座、排针、网口、SD 卡座这类**外接接口必须布置在板边**，原因有三：

- 插拔时不会碰到板上其他器件
- 外壳开孔位置自然对齐
- 走线短，减少引线电感

把 USB 座放在板子正中央，是新手最经典的布局错误之一。

## 2.3 数模分区

模拟电路（ADC 前端、运放、基准源）与数字电路（MCU、晶振、高速总线）应**物理分区**，中间用地平面隔离带分隔，模拟地采用**单点接地**汇入主地平面。

判断标准很简单：**模拟信号线不要穿越数字区域**。

## 2.4 热设计：散热焊盘与热过孔

- 功率器件（LDO、MOS、驱动）下方铺铜散热，并打**热过孔（thermal via）**阵列把热量导到背面铜皮
- 温升估算：$T_{rise} \approx P \times R_{\theta}$，功耗越大越需要散热面积
- TO-252 / DPAK 类带散热焊盘的器件，**散热焊盘必须焊接到铺铜**，否则过热保护或降额

## 2.5 结构与装配对齐

- 安装孔（螺丝孔）避开走线与器件，并做非金属化孔 + 禁布区
- 连接器朝向一致、防呆（用缺口/异形座）
- 板边留出 3~5 mm 禁布带，避免铣边切伤走线
- 需要外壳的板子，螺丝孔位置与外壳严格对齐

## 2.6 天线净空

板载无线（蓝牙/WiFi/LoRa）模块的天线区域**正下方及四周 5 mm 内禁止走线、铺铜、放金属件**，否则辐射效率骤降、通信距离缩水。天线区域最好做净空开窗（不铺铜、无阻焊覆盖）。

## 2.7 测试点与基准点

- **测试点（TP）**：在关键信号（3.3 V、GND、SWD、UART、晶振）预留焊盘，便于针床或探针测量
- **基准点（Fiducial）**：贴片机定位用，板角放 2~3 个直径 1 mm 的裸铜圆点（无阻焊、无走线）
- 量产前这两样是自动化测试与贴片对位的基础

## 2.8 拼板与可制造性（DFM）

- 小板打样常**拼板（panelization）**以提高贴片效率：V-cut（V 形槽）适合直线分离，邮票孔（mouse bite）适合异形
- 板边留 5 mm 工艺边放基准点与夹紧区
- DFM 自检：丝印是否压焊盘、器件间距是否满足返修、极性是否标注、是否有孤立死铜

## 2.9 安规间距（爬电与电气间隙）

涉及强电（220 V）时，不同电位间需满足**爬电距离/电气间隙**要求，通常 ≥ 0.5 mm/100 V 量级（具体查安规标准）。低压数字板一般无需，但高压区务必留够。

## 2.10 布局禁忌清单

| ❌ 错误做法 | ✅ 正确做法 | 原因 |
| --- | --- | --- |
| 晶振远离 MCU 摆放 | 晶振紧贴 OSC 引脚，外层包地 | 减少寄生电容与干扰耦合 |
| 去耦电容放在芯片远处 | 紧贴 VDD 引脚，先电容后过孔 | 瞬态电流回路最短 |
| 大电流走线与微弱模拟线长距离平行 | 正交或拉开距离 | 耦合噪声 |
| 器件紧紧挨在一起 | 预留焊接与返修空间（≥0.3 mm） | 手工返修可行 |
| 电感、晶振下方走线 | 下方掏空或铺地 | 避免耦合与阻抗突变 |
| BOOT 引脚悬空 | 10 kΩ 下拉到地 | 启动模式不确定 |
| 天线下方铺铜 | 净空开窗 | 保通信距离 |

## 2.11 布局自检流程

完成布局后，按顺序过一遍：

- [ ] 所有连接器都在板边，插拔方向朝外
- [ ] MCU 四个方向都留有布线通道
- [ ] 每个 VDD 引脚旁都有去耦电容，距离 < 2 mm
- [ ] 晶振紧贴 OSC，包地完整，下方无走线
- [ ] 模拟/数字区域已分区，无穿插
- [ ] 散热焊盘已铺铜打热过孔
- [ ] 天线区域已净空
- [ ] 测试点/基准点已留
- [ ] 器件间距满足手焊与返修要求
- [ ] 板框、安装孔与外壳尺寸一致

## 本章要点

- 布局顺序：MCU → 晶振/复位 → 去耦 → 电源 → 接口
- 外接接口一律靠板边；数模分区，模拟线不穿越数字区
- 热设计靠散热焊盘 + 热过孔；结构与天线净空常被忽略
- 测试点/基准点支撑量产测试；拼板与 DFM 关乎可制造性
- 晶振紧贴、去耦就近、大电流与弱信号隔离
