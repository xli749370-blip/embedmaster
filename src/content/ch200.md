# 第一章 PCB 设计全景：流程、工具与选型

> 后面五章讲的是具体技法：怎么画封装、怎么布局、怎么布线、怎么出生产文件。但在动手之前，有一件事比任何技法都重要——你得先知道自己要走的是哪条路。层数选错、工具选错、板材选错，后面画得再漂亮也是白费。

## 1.1 一块板子是怎么从想法变成实物的

完整的 PCB 设计流程是六步，每一步都有明确的产出物：

| 步骤 | 做什么 | 产出 |
|---|---|---|
| 1. 需求与选型 | 确定功能、接口、尺寸、供电、主控 | 需求清单、BOM 草案 |
| 2. 原理图设计 | 画连接关系，分配引脚与网络 | 原理图、网表 |
| 3. 封装库准备 | 为每个器件准备焊盘图形 | 封装库 |
| 4. 布局 | 决定器件在板上的位置 | 布局图 |
| 5. 布线 | 连接所有网络，处理电源与地 | 走线完成图 |
| 6. 检查与出板 | DRC、Gerber、坐标文件 | 生产文件包 |

**新手最常犯的流程错误是"画完原理图就直接布线"。** 中间少了封装核对和布局规划，结果是画到一半发现某个器件放不下、或者关键信号路径绕了整块板。

还有一个隐性但关键的步骤：**布线之前先定设计规则。** 线宽、间距、过孔尺寸这些如果不在开始时设好，画完再改会导致大量返工。

## 1.2 工具选型

| 工具 | 特点 | 适用 |
|---|---|---|
| **立创EDA** | 在线、免费、元件库与商城打通、中文界面 | 入门、小批量、快速打样 |
| **KiCad** | 开源免费、跨平台、社区活跃、库管理规范 | 学习、开源项目、中等复杂度 |
| **Altium Designer** | 行业主流、功能完整、3D 与高速仿真强 | 商用产品、复杂板 |
| **PADS** | 中小型企业常用、布线手感好 | 消费电子、工控 |
| **Cadence Allegro** | 高端、高速信号与多层板强 | 通信、服务器、芯片原厂 |

**给初学者的实际建议：从立创EDA或KiCad起步。** 理由不是"免费"，而是它们的元件库和封装库是配套的——你选的元件直接带符号和封装，能避开"符号画好了但封装尺寸查不到"这个最耗时间的坑。Altium 功能更强但对新手是负担，且正版授权成本高。

本课程的所有操作示范以**立创EDA专业版**为主，其他工具的菜单名称不同，但设计思想和判据完全一致。

## 1.3 层数怎么选

这是新手最容易选错、代价又很大的一个决策。

| 层数 | 结构 | 成本（约） | 适用场景 |
|---|---|---|---|
| 单面板 | 1 层铜 | 最低 | 极简电路、教学、成本敏感 |
| 双面板 | 2 层铜，双面走线 | 低 | 绝大多数入门与中小批量项目 |
| 4 层板 | 信号-地-电源-信号 | 中（约双面的 2~3 倍） | 有 MCU + 高速信号、要求 EMC |
| 6 层及以上 | 多组信号/地 | 高 | 高速总线、DDR、射频 |

**关键判据：有没有完整的地平面。**

双面板的地是"用走线拼出来的"，回流电流必须沿着信号线旁边的铜皮绕行，路径长、环路面积大，容易辐射也容易被干扰。4 层板把整个第二层做成完整地平面，信号的回流电流直接在正下方的地平面上流回源端，环路面积接近零。

**什么时候必须上 4 层？**

- 有 USB、以太网、SDIO 等需要阻抗控制的接口
- 有开关电源（DC-DC）且对纹波敏感
- 板上有 ADC 采微弱信号
- 需要通过 EMC 认证
- 器件密度高，双面布不通

**什么时候双面够用？**

- 纯数字低速电路（按键、LED、继电器、数码管）
- STM32 最小系统 + 少量外设，速率 < 10MHz
- 教学demo、验证板

本课程的 STM32 最小系统案例用**双面板**，这已经足够，也是大多数真实项目的起点。

## 1.4 板材与工艺参数

下单时打样厂会让你填一堆参数，需要知道哪些重要：

| 参数 | 常见值 | 说明 |
|---|---|---|
| 板材 | FR-4 | 玻璃纤维环氧树脂，通用材料 |
| 板厚 | 1.6 mm | 标准值；1.2/0.8 用于薄型设备 |
| 铜厚 | 1 oz（35 μm） | 2 oz 用于大电流；成本上升 |
| 阻焊 | 绿色/黑色/白色/蓝色 | 只影响外观，绿色最便宜最通用 |
| 表面处理 | 喷锡（HASL）/ 沉金（ENIG） | 喷锡便宜；沉金平整、适合细间距和长期存放 |
| 最小线宽/间距 | 6/6 mil 或 5/5 mil | 打样厂常规能力；更细加价 |

**铜厚与载流能力直接相关。** 1oz 铜、1mm 宽的走线，温升 10℃ 时约能承载 1A；2A 需要约 2mm 或 2oz 铜。大电流路径（电机、电源输入）必须按这个算，不能凭感觉画。

**沉金（ENIG）不只是"更好看"。** 喷锡表面不平整，0.5mm 间距以下的 QFN/BGA 焊盘容易出现锡桥或虚焊；沉金平整且抗氧化，长期存放（超过半年）仍可焊接。器件有细间距封装时值得加钱。

## 1.5 设计规则：动手前先定好

这些数值在布线前就该写进软件，而不是画完再查：

| 项目 | 常规值 | 说明 |
|---|---|---|
| 信号线宽 | 6–10 mil | 普通数字信号 |
| 电源线宽 | 15–30 mil | 按电流计算，1A 约 1mm |
| 最小间距 | 6 mil | 与线宽同级别 |
| 过孔孔径/外径 | 0.3/0.6 mm | 常规；0.2/0.45 为微孔，加价 |
| 焊盘环宽 | ≥ 0.15 mm | 太小容易钻孔破环 |
| 丝印线宽 | 0.15 mm | 太细印不出来 |
| 板边留空 | ≥ 0.3 mm | 太靠边铣切会伤铜 |

**为什么线宽不能随手画？** 因为线宽决定了三件事：载流能力、阻抗、以及加工良率。6mil 以下需要打样厂确认工艺能力，8mil 以上几乎所有厂都能稳定做。**第一次打样建议全部 ≥ 6mil、过孔 ≥ 0.3mm**，把良率风险降到最低。

## 1.6 本课程路线图

接下来五章是一条完整的实操链：

1. **封装库与焊盘基础**——尺寸只能信 Datasheet，这里错了后面全废
2. **布局基础原则**——决定 80% 的电气性能，也是新手最不重视的一步
3. **布线、电源与信号**——线宽、转角、过孔、差分、回流路径
4. **DRC 与 Gerber 输出**——把设计变成工厂能读的文件
5. **STM32 最小系统综合案例**——完整走一遍真实设计流程

**学习的正确顺序是"跟着做完一遍，再回头理解原理"。** PCB 设计有很多经验性判断（比如"晶振要靠多近"），只看文字记不住，画一遍、打样一次、焊一次，才会真正变成你的东西。

## 1.7 本章小结

- 完整流程六步：需求 → 原理图 → 封装 → 布局 → 布线 → 检查出板，中间没有可以跳过的环节。
- 工具从立创EDA或KiCad起步，库配套能省下最耗时的封装核对。
- 层数的关键是"有没有完整地平面"，双面够用于低速数字电路，有阻抗控制或微弱信号就上 4 层。
- 板材 FR-4 / 1.6mm / 1oz 是标准组合；细间距器件建议沉金。
- 布线前先定设计规则，首板全部 ≥ 6mil、过孔 ≥ 0.3mm，把良率风险降到最低。
