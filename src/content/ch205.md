# 第六章 STM32 最小系统板综合案例

> 把所有知识串起来：从 BOM 到布局、从布线到 DRC，完整走一遍 STM32 最小系统板的设计流程。这一章会做具体数值计算，并给出故障树和量产思路。

## 5.1 必备功能模块

| 模块 | 器件 | 关键参数 |
| --- | --- | --- |
| 主控 | STM32F103C8T6（LQFP48） | 72 MHz，64 KB Flash |
| 电源 | AMS1117-3.3（SOT-223） | 5 V → 3.3 V，最大 800 mA |
| 输入滤波 | 10 µF + 0.1 µF | 抑制上电浪涌 |
| 复位 | 10 kΩ 上拉 + 100 nF + 按键 | $\tau = 1\,\text{ms}$ |
| 高速晶振 | 8 MHz + 2×20 pF | HSE，误差 ±20 ppm |
| 低速晶振 | 32.768 kHz + 2×10 pF | LSE，RTC 用，可选 |
| BOOT | 10 kΩ 下拉（BOOT0） | 确保从 Flash 启动 |
| 去耦 | 每个 VDD 引脚 0.1 µF | 共 4 颗（VDD_1~3 + VDDA） |
| 调试 | 4 pin SWD（3.3V/SWDIO/SWCLK/GND） | 必须留出 |
| 指示 | 电源 LED + 用户 LED（1 kΩ 限流） | |

## 5.2 关键数值计算（别凭感觉）

**1. 复位时间常数**
$$\tau = R \times C = 10\,\text{k}\Omega \times 100\,\text{nF} = 1\,\text{ms}$$
电源爬坡期间 NRST 被拉低约 3~5 ms 才释放，保证 MCU 完成上电复位。

**2. 晶振负载电容**
无源晶振要求两端各接 $C_L$，且 $C_L \approx \frac{C_1 C_2}{C_1 + C_2} + C_{stray}$。若规格书要求 $C_L=20\,\text{pF}$、杂散电容约 5 pF，则外部两颗取：
$$C_1 = C_2 = 2(C_L - C_{stray}) = 2(20-5) = 30\,\text{pF}$$
常用标称 22~33 pF，取 20 pF 也普遍可用。

**3. 电池检测分压**（若涉及）
电池经 $R_1=100\,\text{k}\Omega$、$R_2=10\,\text{k}\Omega$ 分压，读数 ×11 即真实电压，功耗仅微瓦级。

**4. LED 限流**
用户 LED 用 3.3 V 驱动、正向压降 1.8 V、期望 2 mA：
$$R = \frac{3.3 - 1.8}{0.002} = 750\,\Omega \approx 680\,\Omega \text{（标称）}$$

## 5.3 布局顺序（实战）

1. 放置 **LQFP48 主控**，旋转到引脚排布最利于布线的方向
2. 四个 VDD 引脚旁各放一颗 **0.1 µF**，紧贴引脚
3. **8 MHz 晶振 + 20 pF×2** 贴住 OSC_IN/OSC_OUT，外层包地
4. **复位电路**靠近 NRST，按键放在板边便于按压
5. **AMS1117 + 10 µF/0.1 µF** 放在电源入口附近，散热焊盘朝外
6. **USB / DC 座 / 排针** 全部布置在板边
7. **SWD 排针** 放在板边或角落，方便接线不碰其他器件

## 5.4 布线要点

- 3.3 V 主电源线宽 **≥ 0.5 mm**，5 V 输入 **≥ 1 mm**
- 晶振走线尽量短、等长，两侧用地铜包围，下方不走线
- SWD 的 SWCLK 与 SWDIO 尽量短，避免与晶振线并行
- 底层整片铺 GND，顶层铺地后多打过孔缝合
- 复位线远离晶振与电源开关节点

## 5.5 七大踩坑点

1. **晶振负载电容选型错误** → 不起振或频偏，必须按晶振规格书取 $C_L$
2. **去耦电容距离 VDD 太远** → 高频去耦失效，表现为随机复位
3. **BOOT0 悬空** → 启动模式不确定，偶发不启动
4. **复位电路缺少上拉电阻** → 上电不稳定、易受干扰复位
5. **电源走线过窄** → 压降大、发热，带负载时电压跌落
6. **晶振走线过长或下方走线** → 引入干扰，起振困难
7. **SWD 未留出或引脚顺序错** → 板子焊好后无法烧录，直接报废

## 5.6 上电调试顺序

1. **不焊 MCU**，先上电测 3.3 V 轨电压是否在 3.3 ± 5%
2. 测 AMS1117 输入输出压差与温升
3. 焊 MCU，测 NRST 是否为高（约 3.3 V）
4. 用示波器看 8 MHz 晶振是否起振（注意探头电容会影响起振）
5. 连 SWD，读 ID 确认芯片识别正常
6. 烧录点灯程序，验证最小系统闭环
7. 逐步加入外设，每次只加一个模块

## 5.7 故障树（排错导航）

```
板子不工作
├─ 3.3V 无输出 ──→ LDO 输入/使能/焊点、输入电压
├─ MCU 不启动 ──→ NRST 电平、BOOT0、晶振起振、VDDA 供电
├─ 连不上 SWD ──→ 四针顺序、线序、目标板供电、速率过高
├─ 晶振不起振 ──→ 负载电容、走线长度、下方走线、探头电容
└─ 程序跑飞 ──→ 去耦不足、电源纹波、复位干扰
```

## 5.8 示波器看什么

- **NRST**：上电应是一个从 0 缓慢升到 3.3 V 的曲线（约 1 ms），不是直上直下
- **8 MHz 晶振**：正弦/方波，幅度约 0.5~1 V，频率偏差在 ppm 级
- **SWDIO/SWCLK**：烧录时有规律的数据波形
- **3.3 V 轨**：纹波应 < 50 mV，用交流耦合档看

## 5.9 量产与版本管理

- **批量烧录**：用 ST-Link + 脚本批量烧固件，并写入唯一序列号（存 Flash）
- **丝印**：板面标注版本号（V1.2）、极性、1 脚方向，方便追溯
- **质检**：抽样测 3.3 V 纹波、晶振频率、SWD 可读、点灯通过
- **工艺备注**：下单时注明板厚 1.6 mm、1 oz 铜、绿油、沉金/喷锡

## 本章要点

- 最小系统 = 主控 + 电源 + 复位 + 晶振 + 去耦 + 调试口
- 数值要算：复位 τ、晶振 $C_L$、分压比、LED 限流
- 布局顺序决定布线难度；七大踩坑点覆盖 90% 首次失败
- 上电调试「先电源后芯片、先最小后外设」
- 故障树 + 示波器三处波形是定位利器；量产要烧录/序列号/质检
