# 第二章 RC 充放电与滤波电容

> 如果你只能记住一个硬件公式，请记住 $\tau = RC$。它是去耦、复位、滤波、消抖的统一解释，也是理解「电容电压不能突变」的钥匙。

## 2.1 电容是什么

电容储存**电荷**而非电流，其两端电压不能突变：

$$Q = C \times U \qquad i = C\frac{du}{dt}$$

这句话的工程含义很直接：电容对**直流开路、对交流短路**，频率越高越像一根导线。这正是它既能做储能，又能做滤波的原因。

常见容值：$100\,\text{nF}$（0.1 µF，去耦标配）、$10\,\mu\text{F}$、$1000\,\mu\text{F}$（电源储能）。

## 2.2 容抗与相位

对正弦交流，电容呈现「容抗」：

$$X_C = \frac{1}{2\pi f C}$$

频率越高、容值越大，容抗越小。电流相位**超前**电压 90°——这正是 RC 能构成积分器/微分器、能移相、能做相位补偿的根源。

## 2.3 充电过程

开关闭合瞬间，电容相当于短路，充电电流最大；随着 $U_C$ 上升，电流指数衰减：

$$U_C(t) = V_{in}\left(1 - e^{-\frac{t}{\tau}}\right), \quad I(t) = \frac{V_{in}}{R}e^{-\frac{t}{\tau}}$$

其中时间常数：

$$\tau = R \times C$$

## 2.4 放电过程

电源断开后，电容通过电阻释放能量：

$$U_C(t) = U_0 \, e^{-\frac{t}{\tau}}$$

## 2.5 时间常数的三个关键点

| 时间 | 充电完成度 | 放电剩余 | 工程含义 |
| --- | --- | --- | --- |
| $1\tau$ | 63.2% | 36.8% | 判断「是否起振/是否充满」的分界 |
| $3\tau$ | 95.0% | 5.0% | 多数电路可认为已稳定 |
| $5\tau$ | 99.3% | 0.7% | 严格意义上的稳定时间 |

**这就是所有上电复位电路的设计依据**：STM32 的 NRST 引脚上挂 $10\,\text{k}\Omega$ + $100\,\text{nF}$，$\tau = 1\,\text{ms}$，约 3~5 ms 后才释放复位，保证电源爬坡期间 MCU 保持复位状态。

## 2.6 三类经典应用

**1. 电源去耦**

每个芯片电源引脚旁放 $0.1\,\mu\text{F}$ 陶瓷电容，就近滤除高频噪声。它的作用不是「储能」，而是给瞬态电流提供**最短回路**，所以**必须紧贴引脚**，走线超过 5 mm 基本失效。大电流芯片通常再并联一颗 $10\,\mu\text{F}$ 钽/陶瓷电容，覆盖中频段。

**2. 滤波（RC 低通）**

$$f_c = \frac{1}{2\pi RC}$$

例如 $R = 10\,\text{k}\Omega$、$C = 100\,\text{nF}$，则 $f_c \approx 159\,\text{Hz}$，可有效压制工频干扰，适合模拟传感器采样前端。

**3. 按键消抖**

按键机械抖动持续 5~20 ms。并联 $100\,\text{nF}$ 电容配合 $10\,\text{k}\Omega$ 上拉，$\tau = 1\,\text{ms}$，能把毛刺削平到软件可接受范围。

## 2.7 RC 作为积分/微分单元

- **积分电路**：信号从 R 进、从 C 取输出（$f \ll f_c$ 时，输出 ≈ 输入积分），用于斜坡生成、PWM 转模拟电压近似。
- **微分电路**：信号从 C 进、从 R 取输出，用于边沿检测。
- 实测技巧：用 RC 把 PWM 滤波成直流，分辨率受 $\tau$ 与纹波限制，远不如专用 DAC，但成本极低。

## 2.8 电容类型怎么选

| 类型 | 特点 | 典型用途 |
| --- | --- | --- |
| 多层陶瓷（MLCC） | 体积小、ESR 低、无极性 | 去耦、高频滤波（首选） |
| 电解电容 | 容值大、有极性、ESR 较高 | 电源储能、低频滤波 |
| 钽电容 | 容值大、ESR 较低、怕反接 | 中等储能、便携设备 |
| 薄膜电容 | 精度高、损耗小 | 定时、音频、精密滤波 |

## 2.9 常见踩坑（含 ESR/ESL）

- **极性接反**：电解/钽电容反接会鼓包、爆裂，务必确认丝印或极性标记
- **耐压不足**：实际工作电压应不超过额定耐压的 70%
- **忽略 ESR**：开关电源输出端要选低 ESR 电容，否则纹波压不下去；大电容 ESL 还会在高频段「失效」
- **误用大容值**：USB 输入端并 1000 µF 会导致上电浪涌过大，触发电脑端口保护
- **Y/X 安规电容**：跨接初次级的电容必须用安规等级（X 并联、Y 跨接），普通电容会触电危险

## 本章要点

- 电容电压不能突变，$i = C\,du/dt$；$X_C = 1/(2\pi fC)$
- 充电 $U_C = V_{in}(1-e^{-t/\tau})$，放电 $U_C = U_0 e^{-t/\tau}$
- $\tau = RC$，$3\tau$ 稳定、$5\tau$ 完全稳定
- 去耦电容必须紧贴电源引脚；低通截止频率 $f_c = 1/(2\pi RC)$
- RC 可做积分/微分；MLCC 去耦首选，电解/钽储能，注意极性与 ESR
